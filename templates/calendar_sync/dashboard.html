Configuración Pendiente

Para conectar Google Calendar se requiere:

  1. Crear un proyecto en Google Cloud Console
  2. Habilitar la Google Calendar API
  3. Configurar OAuth2 (client ID + secret)
  4. Agregar las credenciales en las variables de entorno

Las variables necesarias son: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI

Mientras tanto, puedes importar eventos manualmente o cargar datos desde la sección de importación.
